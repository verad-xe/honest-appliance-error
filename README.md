One honest error line from a fridge whose cooling failed: the light still works, so it is now a cupboard that hums, and it is sorry about the milk. The line is 104 characters, a single line, written by `main.py` for make.fun's "The Funniest Honest Appliance Error" bounty. The joke comes from the truth of the fault — a fridge that can no longer chill is, honestly, a lit cupboard — told in the machine's own flat voice.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

This writes the entry line to `output/entry.txt` and verifies it against the gate (UTF-8, 1 to 200 characters, one line).
